# Changelog

## 1.1.0 — 2026-10-17

- Redesigned the visual identity with a custom sculpted brandmark and coordinated color treatment.
- Updated favicon, README banner, mobile/desktop screenshots, and all installation icons.
- Added a transparent brandmark and a concise identity guide.
- Versioned the offline cache so existing browser visits receive the refreshed assets.

## 1.0.0 — 2026-10-17

Initial public release.

- Keep live clocks for 17 curated IANA time zones, including Almaty.
- Compare a UTC meeting time across locations and local dates.
- Account for daylight-saving changes using the browser’s Intl database.
- Find shared whole-hour start times across daytime work windows.
- Original visual identity, responsive menu, and mobile app icons.
- Installable offline PWA, local persistence, validated JSON backups.
- Product tests, install-asset checks, and contributor documentation.
